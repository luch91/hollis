# Repository Instructions

Before changing this repository, read `.hollis/decisions.md` if it exists. That ignored file is the controlling private decision log.

Run `pnpm verify` before proposing or committing a change. Do not bypass hooks or weaken repository policy checks.

If a requirement is unclear, stop and consult the decision log. If the answer is not recorded, request an explicit decision or add it to the open-decision list. Do not guess.
