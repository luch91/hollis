## Root causes closed during this run

1. Production was missing the signed-checkpoint and adjacent audit/retention migrations. The exact
   checked-in migrations were applied transactionally and journaled with their checked-in hashes.
2. The review UI treated an export failure as though no selected case existed. A selected case now
   stays usable and shows an explicit audit/commitment warning while unsafe attestation remains
   blocked.
3. GenLayer V8 expected a nested canonical policy control, while Hollis' canonical schema stores
   those commitment fields flat. V9 validates the actual canonical shape and separately validates
   and cross-checks the complete policy control.
4. A failed legacy submission previously prevented a corrected contract from taking over. Failed
   or reconciliation-required legacy submissions can now roll forward to V9, while submitted and
   finalized records remain immutable.
5. Submission idempotency is deployment-scoped, preventing a corrected deployment from colliding
   with the failed legacy attempt without permitting duplicate writes to the same deployment.
